# radiohub.tech

Сайт РадиоХаба: 8 станций в прямом эфире, 20 тематических потоков, городские эфиры, подкасты. Статический сайт на Next.js: собирается в папку `out/`, на сервере нужен только раздающий файлы веб-сервер.

## Команды

```bash
npm install
npm run snapshot   # забрать свежие данные с бэкенда приложения → data/catalog.json, public/media, public/geo
npm run build      # собрать сайт в out/ (≈10 с, 162 страницы)
npm run serve      # посмотреть сборку: http://localhost:3200
npm run dev        # режим разработки: http://localhost:3100
```

Каталог (станции, потоки, города, подкасты) берётся со снимка, а не с бэкенда на лету. Чтобы обновлялись новые выпуски подкастов, достаточно раз в сутки запускать `npm run snapshot && npm run build` и выкладывать `out/`. «Сейчас в эфире» и история эфира приходят в браузер напрямую с `meta.hostingradio.ru`, их обновлять не нужно.

## Что внутри

| Страница | Адрес | Что там |
|---|---|---|
| Главная | `/` | все 8 станций карточками в цвет станции: что играет сейчас, кнопка эфира и значки потоков (включаются одним нажатием); подкасты |
| Станция | `/station/<станция>/` | эфир и ряд потоков прямо в шапке, видеоэфир, подкасты, поиск по городам, кнопка «Найти эфир моего города», другие станции |
| Поток | `/station/<станция>/<поток>/` | 20 штук |
| Город | `/station/<станция>/city/<город>/` | только 89 городов со своим эфиром (не общий и не областной поток), чтобы не плодить одинаковые страницы |
| Подкасты | `/podcasts/`, `/podcasts/<шоу>/` | 38 шоу, последние 24 выпуска каждого играют на сайте |
| Города | `/cities/` | все 586 городов и какие станции там звучат |
| Приложение | `/app/` | магазины и QR; с QR телефон сразу уходит в свой магазин |

Плеер внизу не прерывается при переходах. Кнопка «Что играло» открывает панель с историей эфира (30-секундные превью) и переключателем потоков станции. Последняя станция и громкость запоминаются. Работают экран блокировки и кнопки гарнитуры (переключают станции). Частот на сайте нет намеренно.

Город выбирается один раз на весь сайт (кнопка в шапке) и меняет только основные эфиры станций, потоки и подкасты везде одинаковые; без города играет федеральный эфир. При первом входе город угадывается по IP (get.geojs.io), и сайт ненавязчиво спрашивает «Ваш город — …?»; ответ запоминается. В окне выбора есть поиск и «Определить по геопозиции» (только по нажатию). Список городов с их эфирами лежит в `public/geo/cities.json`. Трансляция из студии открывается мини-плеером в углу и не пропадает при переходах по сайту. Координаты всех городов взяты из справочника [hflabs/city](https://github.com/hflabs/city) (`data/ru-cities.csv`), недостающие найдены через OpenStreetMap и лежат в кэше `data/geo-cache.json`.

## Открытие в приложении (ФТ «ссылки в приложение»)

- `public/.well-known/assetlinks.json`: `com.radiohub` и SHA-256 ключа Google Play из ФТ. Если в ответе команда приложения пришлёт upload-ключ и ключ тестовых сборок, их надо дописать в массив.
- `public/.well-known/apple-app-site-association`: `NR7VRAP936.com.emg.radiohub` (команда и bundle id из проекта iOS). Сервер должен отдавать этот файл с `Content-Type: application/json`.
- Android: баннер сверху страницы и кнопка «Открыть в приложении» ведут на `intent://radiohub.tech/<тот же адрес>`. Пока приложение не принимает ссылки, Chrome уводит в Google Play. Когда App Links заработают, эти же кнопки начнут открывать нужную станцию без правок сайта.
- iOS: системный Smart App Banner (`apple-itunes-app`, id 6761184795) с адресом страницы в `app-argument`.
- Ссылки в магазины с метками `utm_source=radiohub.tech`.

## Выкладка

Подойдёт любой статический хостинг или nginx:

```nginx
root /var/www/radiohub.tech/out;
location / { try_files $uri $uri/index.html =404; }
error_page 404 /404.html;
location = /.well-known/apple-app-site-association { default_type application/json; }
```

## Откуда данные

- Станции, потоки, города, подкасты: `https://back-radiohub.vvdev.ru/api` (тот же бэкенд, что у приложения; переменная `RADIOHUB_API`, если адрес сменится).
- Эфир: потоки HLS `*.emgsound.ru`. Метаданные идут через `wss://meta.hostingradio.ru/emg/ws?format=native`, одно подключение на все станции, как у europaplus.ru. Если открыть отдельный сокет на каждую станцию, сервер отвечает 429.
